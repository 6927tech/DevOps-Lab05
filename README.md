# เกมต่อจิ๊กซอว์รถยนต์

เกมจิ๊กซอว์ 20 ชิ้น สร้างด้วย HTML, CSS และ JavaScript โดยใช้ภาพ `car.webp`

## วิธีเล่น

เปิดไฟล์ `index.html` ด้วย browser บนเครื่อง PC แล้วลากชิ้นส่วนจากถาดด้านขวามาวางในพื้นที่ต่อภาพด้านซ้าย ชิ้นส่วนจะเข้าที่เมื่อวางใกล้ตำแหน่งที่ถูกต้อง โดยไม่มีภาพตัวอย่างช่วยบอกคำตอบ

เพลงบรรเลงจะเริ่มเมื่อเริ่มลากชิ้นส่วน พร้อมเสียงคลิกเมื่อหยิบหรือวางชิ้นส่วน สามารถเปิดหรือปิดเพลงและเสียงเอฟเฟกต์ได้จากปุ่มด้านล่างเกม ตัวจับเวลาเริ่มเมื่อเริ่มเล่นและหยุดเมื่อประกอบภาพครบ โดยจะแสดงเวลาที่ใช้พร้อมเสียงฉลองเมื่อจบเกม

กด **เริ่มเกมใหม่** เพื่อสุ่มตำแหน่งชิ้นส่วนอีกครั้งและเริ่มจับเวลาใหม่
